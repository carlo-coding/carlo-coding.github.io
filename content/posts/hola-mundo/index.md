Este blog existe para escribir lo que voy aprendiendo y construyendo, sin prisa y sin adornos.

## Cómo está hecho

Cada post es un archivo de Markdown en una carpeta. Con eso se genera una página estática, y la ilustración de cada post se dibuja a mano en SVG.

```bash
npm run dev
```

Si algo de esto te sirve, mejor. Si no, al menos queda anotado.
